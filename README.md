# 코인 차트 단타 레이더 — 완전 신규 설계

- 업비트 KRW 전체 종목 중 **최근 24시간 누적 거래대금 10억원 이상**만 분석합니다.
- 완성된 1시간봉과 4시간봉을 이용해 RSI, MACD, EMA, 볼린저밴드, ADX, 스토캐스틱, ATR, 거래량, 고점 돌파, 저점 상승, 캔들 아래꼬리를 분석합니다.
- 1시간봉 점수 72%, 4시간봉 점수 28%의 종합 점수로 TOP 20을 정합니다. 4시간봉 약세는 추가 감점합니다.
- **1시간 상승확률**은 과거 1시간봉 *단독* 점수 구간별 다음 1시간봉 종가 상승 빈도를 통계 보정한 값입니다. TOP 20의 종합점수에 대응하는 검증된 확률은 아닙니다.
- 과거 데이터의 시간순 70%를 학습, 나중 30%를 검증에 사용합니다. 검증 적중률과 Brier 점수를 표시합니다. 학습 60건·검증 20건 미만 점수 구간은 `검증 부족`입니다.
- GitHub Actions는 매시간 실행하고 `data/latest.json`과 `data/history.json`을 함께 저장합니다. 72시간이 지난 기록은 삭제합니다.
- 관심종목 선택은 해당 브라우저의 localStorage에 저장합니다. 다른 기기와 동기화되지 않습니다. 관심종목의 점수 기록은 분석 대상에 계속 포함된 경우에만 그래프에 나타납니다.

## 설치 (기존 V1~V5와 혼합 금지)

1. 새 GitHub 저장소를 만들거나 기존 저장소를 비운 후 이 ZIP **내부 구조 그대로** 업로드합니다. `.github/workflows/analyze.yml`이 포함되어야 합니다.
2. 저장소 Settings > Actions > General > Workflow permissions에서 `Read and write permissions`를 허용합니다. 필요하다면 GitHub Pages를 `main / (root)`로 설정합니다.
3. Actions > **Coin Chart Scalp Radar** > Run workflow를 누릅니다. 실행 완료 후 `data/latest.json`, `data/history.json` 생성 여부를 확인합니다.
4. GitHub Pages 주소로 `index.html`을 열어 확인합니다. 단독 HTML 파일을 휴대폰 파일앱에서 열면 GitHub Actions의 JSON 데이터가 없어 순위가 표시되지 않습니다.
5. 기존 `Upbit Hourly Analysis` 워크플로가 남아 있다면 **중복 실행을 피하도록 비활성화**하세요. 새 워크플로와 기존 워크플로가 동일한 파일을 갱신하지 않도록 해야 합니다.

## 한계와 안전

- 자동 매매가 아니며, 투자 수익이나 상승을 보장하지 않습니다.
- 데이터는 매시간 갱신되며 실시간 틱 분석이 아닙니다. GitHub Actions 예약 실행은 지연될 수 있습니다.
- 과거 200개의 1시간봉과 150개의 4시간봉을 사용합니다. 시장 국면 변화, 수수료, 슬리피지, 미래 유동성, 거래소 장애는 백테스트에 반영하지 않습니다.
- 기술적 점수의 고득점과 높은 상승확률은 다릅니다. 확률 모형은 과거 1시간봉의 유사 점수 구간을 바탕으로 하므로 개별 종목에 대한 충분한 장기 검증이 아닙니다.
- 사용 가능한 1시간봉 또는 4시간봉이 65개 미만이면 점수를 강제로 계산하지 않고 `insufficient_history`로 분류합니다.
